## Overview

The Legend faithfully models the analog circuitry of the Roland TB-303 bass synthesizer with transistor-ladder filter simulation, accent dynamics, and slide behavior for authentic acid bass sequences.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Synapse The Legend** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Transistor Ladder** | Discrete component model of the TB-303 diode-ladder filter |
| **Accent Dynamics** | Authentic accent behavior matching the original envelope circuit |
| **Slide Mode** | Portamento behavior tuned to the TB-303 capacitor discharge timing |
| **Pattern Sequencer** | Built-in step sequencer mimicking the original 303 interface |
